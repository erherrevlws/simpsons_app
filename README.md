# Catálogo de Personajes - Los Simpson 

Prototipo móvil desarrollado en Flutter para explorar un catálogo de personajes consumiendo la API pública de The Simpsons, desarrollado como Tercer Examen Práctico para  Desarrollo de Aplicaciones Móviles.

##  Funcionalidades Principales
- **Catálogo Paginado:** Visualización en tarjetas con imagen, nombre, estado y ocupación del personaje.
- **Búsqueda Local:** Filtrado en tiempo real por nombre dentro de la página actual.
- **Detalle de Personaje:** Ficha completa con datos adicionales (género, edad y frases icónicas).
- **Favoritos Persistentes:** Almacenamiento local de personajes favoritos que perduran al reiniciar la aplicación.
- **Manejo de Estados:** Indicadores de carga, control de errores de red y estados de "sin resultados".
